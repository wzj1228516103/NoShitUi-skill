# NODE workflow studio

All interface illustrations, SVG symbols, connector paths, node arrangements,
example text, and styling were created for this repository. NODE uses system
fonts and no remote assets or runtime dependencies.

The three examples are Editorial digest, Review signals, and A little press
note. Execution is a local deterministic simulation: whitespace cleanup,
extractive sentence selection, a documented small English sentiment word list,
and plain-text formatting. No AI model, API, external account, or real service
is called. Saved workflows remain in this browser's local storage. JSON export
contains the graph and parameters, not private service credentials.

The original source is included under the repository's root MIT license.
